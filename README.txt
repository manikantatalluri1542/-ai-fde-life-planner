AI FDE Life Planner — iPhone PWA package

Files:
- index.html: app
- manifest.webmanifest: install metadata
- sw.js: offline cache
- icon-192.png / icon-512.png: app icons

To install on iPhone:
1. Host this folder on an HTTPS static host (GitHub Pages is a free option).
2. Open the published HTTPS address in Safari.
3. Tap Share -> Add to Home Screen -> Add.
4. Launch from the new Home Screen icon.

Progress is stored in Safari on this device. Use Settings -> Export backup before switching devices or clearing website data.
This package is not yet published to the App Store. It is an installable web app (PWA).
